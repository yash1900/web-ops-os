# SEO & Page Rank Department Deep Knowledge Base

## Search Indexing & Sitemap Architecture
1. **Sitemap Files**: `sitemap.xml` in root/public directory of managed web projects.
2. **Meta Contracts**: Single `<h1>` tag per page, Title length 10–60 chars, Meta Description 50–160 chars.
3. **Schema.org Integration**: `schema-templates.json` mapping `Person`, `Organization`, `SoftwareApplication`, `RealEstateListing`.
4. **OpenGraph & Social Cards**: `og:title`, `og:description`, `og:image` properties present in HTML head.
